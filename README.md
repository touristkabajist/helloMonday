# 🌸 樱律 · 出勤管理系统（2026 本地版）

二次元樱花风的纯前端出勤管理系统，**零依赖、零安装、完全离线**，双击 `index.html` 即可在浏览器中使用。

## 🚀 如何打开

- **方式一（最简单）**：直接双击 `index.html`，用 Chrome / Edge 打开。
- **方式二（本地托管）**：在本目录执行任一命令，然后浏览器访问提示的地址：
  - `npx serve .`（需 Node.js）
  - `python -m http.server 8080`（需 Python）

## 🧭 功能地图

| 模块 | 能力 |
| --- | --- |
| 📊 汇总展板 | 部门 2026 年按月出勤率、全年出勤率、缺勤与异常统计、加班分类计时、年假额度看板，支持按部门筛选 |
| 📝 考勤登记 | 月历点击登记，支持全部考勤符号、迟到/早退/旷工异常、备注，自动高亮周末与法定节假日 |
| ⏰ 加班管理 | 记录每次加班/调休的日期、起止时间、时长、事由；按工作日/公休日/法定节假日自动分类并累计计时 |
| 🏖️ 假期管理 | 出差、工伤、调休、疗休养、事假、婚假、病假、产假、护理假、独生子女假、育儿假、年休假；保存后自动把区间内工作日同步为考勤符号，删除时同步清除 |
| 👥 员工与年假 | 以员工为单元的档案库；年度应休/年度已休/本月已休/剩余年假与进度条 |
| 📖 符号对照 | 15 个考勤符号、加班三分类、异常类型说明 |

## 🔣 考勤符号

| 符号 | 含义 | 符号 | 含义 |
| --- | --- | --- | --- |
| V | 出勤 | N | 年休假 |
| W | 出差 | T | 调休 |
| G | 工伤 | S | 事假 |
| / | 休息 | B | 病假 |
| M | 婚假 | P | 产假 |
| C | 护理假 | D | 独生子女假 |
| Y | 育儿假 | L | 疗休养 |
| X | 旷工 | | |

异常类型：迟到、早退、旷工（可与当天符号同时登记）。

## 💾 数据与备份

- 所有数据保存在浏览器 **localStorage**（键名 `anime_attendance_v1`），不上传任何服务器。
- 右上角提供 **⬇ 备份 / ⬆ 恢复**（JSON 文件），换电脑或换浏览器前请先备份。
- 「✨ 示例数据」会生成 4 名员工、2026 年 1–6 月的演示数据，便于直接体验。
- 注意：清理浏览器缓存会清除 localStorage，请定期导出备份。

## 📐 统计口径

- 出勤率 = 当月实际出勤（V 出勤 + W 出差）÷ 应出勤工作日（周一至周五，扣除法定节假日）；当月无登记显示「—」。
- 法定节假日清单维护在 `index.html` 的 `HOLIDAYS` 常量中（2026 年为参考安排，可按国务院正式通知自行调整）；调休上班的周末补班日暂未计入。
- 年假「年度已休」按考勤符号 N 的工作日天数统计。

## 🛠️ 技术说明与后续升级

- 单文件实现：HTML + CSS + 原生 JS，无任何外部 CDN 依赖。
- `_verify.js` 是内置逻辑验收脚本（Node 环境，`node _verify.js`，当前 27 项断言全通过）。
- 当前为单机单浏览器方案；若后续需要多人共用、跨设备同步或真实数据库（SQLite）、登录权限，可以在此基础上升级为 Node + SQLite 的本地服务版，数据模型可平滑迁移。
